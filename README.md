# 家電の事故よぼう

架空の家の見回りメモ4行から、事故につながる家電・電池の使い方を見つける、1日5問の学習ゲーム。
寝ている間の充電・暑い所に置いた電池・ボタン電池の置き場所・たこ足配線・ふくらんだ電池・リコールの調べ方などを、国の資料をもとに練習する。

遊ぶ： <https://satou-aaaaa.github.io/kaden-anzen/>

## 出典

消費者庁・消防庁・NITE（製品評価技術基盤機構）・国民生活センターの公開資料。一覧は `data.js` の `SRC` と、画面の「このゲームについて」。
家・部屋・人はすべて架空で、実在の商品・会社とは関係ありません。製品ごとの使い方は取扱説明書も確かめてください。
